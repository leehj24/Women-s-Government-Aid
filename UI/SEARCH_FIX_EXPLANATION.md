# 검색 정확도 개선 사항

## 문제점

"대구광역시 임산부 체육시설" 검색 시 "임산부와 영유아를 위한 건강 도서실" 같은 관련 없는 정책이 상위에 표시되는 문제

## 원인 분석

1. **다중 키워드 처리 부족**: "대구광역시", "임산부", "체육시설"을 개별 키워드로 처리하지 않음
2. **지역명 인식 부족**: 쿼리에 포함된 지역명을 제대로 추출하지 못함
3. **키워드 매칭 보너스 부족**: 모든 키워드가 매칭되는 경우 보너스가 충분하지 않음
4. **지역 필터링 약함**: 지역 불일치 시 감점이 없음

## 개선 사항

### 1. 키워드 분리 및 지역명 인식

```scala
// "대구광역시 임산부 체육시설" → 
// 지역명: "대구광역시"
// 키워드: Set("임산부", "체육시설")
val (keywords, regionOpt) = splitQueryIntoKeywords(query)
```

### 2. 다중 키워드 매칭 강화

```scala
// 모든 키워드가 매칭되면 50% 보너스
// 70% 이상 매칭되면 20% 보너스
if (allMatched) {
  avgScore * 1.5
} else if (matchedCount >= keywords.size * 0.7) {
  avgScore * 1.2
}
```

### 3. 지역명 매칭 강화

```scala
// 쿼리 지역명이 정책 지역과 일치하면 +0.25 보너스
// 불일치하면 점수 50% 감점
if (matchRegion(queryRegion, policyRegion)) {
  baseScore += 0.25
} else {
  baseScore *= 0.5  // 지역 불일치 시 큰 감점
}
```

### 4. 필드별 가중치 조정

```scala
// 제목: 40% (가장 중요)
// 내용: 30%
// 지원대상: 20%
// 지역: 10% (하지만 쿼리 지역명 일치 시 30%로 증가)
```

### 5. 모든 키워드 매칭 보너스

```scala
// "대구광역시", "임산부", "체육시설" 모두 매칭되면
// +0.4 보너스 (거의 모든 키워드 매칭 시)
if (keywordMatchRatio >= 0.9 && allKeywords.size >= 2) {
  baseScore += 0.4
}
```

## 예상 결과

### "대구광역시 임산부 체육시설" 검색 시

**기존 방식:**
1. "임산부와 영유아를 위한 건강 도서실" (대구, 임산부만 매칭, 체육시설 없음)
2. "대구 임산부 의료비 지원" (대구, 임산부만 매칭, 체육시설 없음)
3. "대구 체육시설 임산부" (모든 키워드 매칭)

**개선된 방식:**
1. "대구 체육시설 임산부" (모든 키워드 매칭, 지역 일치) → **최고 점수**
   - 제목 매칭: 0.4
   - 모든 키워드 보너스: +0.4
   - 지역 일치 보너스: +0.25
   - 총점: 1.05 → 1.0 (정규화)

2. "대구 임산부 체육시설 지원" (모든 키워드 매칭, 지역 일치)
   - 제목 매칭: 0.35
   - 모든 키워드 보너스: +0.3
   - 지역 일치 보너스: +0.25
   - 총점: 0.9

3. "임산부와 영유아를 위한 건강 도서실" (대구, 임산부만 매칭)
   - 제목 매칭: 0.2 (임산부만)
   - 지역 불일치 감점: ×0.5
   - 총점: 0.1 → **낮은 점수**

## 핵심 개선점

1. ✅ **지역명 자동 추출**: 쿼리에서 지역명을 자동으로 인식하고 필터링
2. ✅ **다중 키워드 개별 매칭**: 각 키워드를 개별적으로 매칭
3. ✅ **모든 키워드 매칭 보너스**: 모든 키워드가 매칭되면 큰 보너스
4. ✅ **지역 불일치 감점**: 지역이 맞지 않으면 점수 감점
5. ✅ **핵심 키워드 강조**: "체육시설" 같은 핵심 키워드가 제목에 있으면 더 높은 점수
